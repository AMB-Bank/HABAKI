# ХАБАКИ: Лабиринт — версия с аккаунтами и онлайном

## Запуск
Нужен Node.js 18 или новее (https://nodejs.org). Лучше 22+: тогда аккаунты хранятся в SQLite; на более старом Node сервер сам переключается на JSON-файл (`habaki.json`) — вход и регистрация работают в обоих случаях.

```
npm install
npm start
```
Откройте http://localhost:3000. База (`habaki.db` или `habaki.json`) создаётся сама рядом с `server.js`.

## Что внутри
- `server.js` — сервер: аккаунты (email, имя, пароль — пароли хранятся только в виде хэша scrypt), статистика, рейтинг, онлайн-комнаты по WebSocket.
- `public/index.html` — сама игра, `public/assets.js` — встроенные картинки и песня, `public/three.min.js` — Three.js (работает без интернета).

## Загрузка на хостинг (чтобы работал вход)
Это **не статический сайт**: нужен хостинг, который запускает Node.js (Render, Railway, Fly.io, VPS, панель с «Node.js app»). На Netlify / GitHub Pages / «просто залить файлы» вход и онлайн работать не будут.
- Файлы лежат прямо в корне архива (`server.js`, `package.json`, `public/`) — распаковывайте архив как есть, без лишней папки.
- Команда запуска: `npm start` (или `node server.js`). Порт берётся из `PORT`.
- Проверка, что сервер жив: откройте `/healthz` — должно показать `ok`.
- Если есть Dockerfile-хостинг — он включён в архив.

## Игра по сети с другом
Оба открывают один и тот же адрес сервера. Хозяин: «Онлайн → Создать игру», называет 4-значный код. Друг: «Онлайн» → вводит код → «Войти».

Чтобы играть с другом из другого города, сервер должен быть доступен из интернета: выложите папку на любой хостинг с Node.js (Render, Railway, Fly.io, VPS).
- Для сохранения базы подключите постоянный диск и укажите путь: `DB_FILE=/data/habaki.db`.
- IP клиента берётся из `X-Forwarded-For` (нужно за прокси хостинга). Если прокси нет: `TRUST_PROXY=0`.
- Порт берётся из переменной `PORT`.

## API (для справки)
`POST /api/register`, `POST /api/login`, `GET /api/me`, `POST /api/logout`, `POST /api/stats`, `GET /api/leaderboard`.
